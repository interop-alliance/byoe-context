BYOE Vocabulary

Draft. This vocabulary is a work in progress. Term definitions here are stubs pending the App Connect and WAS Encrypted Collections specifications.

Namespace: https://w3id.org/byoe#

This page defines the terms used by the BYOE (Bring Your Own Everything) application stack: the App Connect wallet protocol and the WAS Encrypted Collections profile. JSON-LD contexts:

  • https://w3id.org/byoe/app-connect/v1

Credential terms

AppKeyCredential
Marker credential type identifying an app-key credential: a self-issued credential carrying the seed from which an app's per-user signing key is derived.
seed
The app-key seed: 32 random bytes, base64url-encoded without padding. The credential subject's DID is derived from this seed.
origin
The web origin the app-key credential is bound to, as attested by the wallet at issuance time.

Presentation terms

zcap
A set of authorization capability delegations included in a wallet's App Connect response presentation.
appConnect
App Connect response metadata (JSON literal), such as whether this was the app's first connection for this user.

Invocation-target descriptor types

collection
An app-scoped storage collection, provisioned when the grant is approved.
public-collection
A plaintext collection with public read access.
shared-collection
A read grant to another user's encrypted collection: a read capability plus an encryption-roster entry, always both.
space
A whole storage Space as an invocation target (read-only ceiling).
managed-collection (reserved)
Reserved for a future write-access descriptor for authoritative apps.
publish-collection (reserved)
Reserved for a future standing-publish-grant descriptor.
collection-policy (reserved)
Reserved for a future runtime policy-control descriptor.
